An entry for [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3?ref=38m33ybw) on make.fun: one sentence, at most 200 characters, that makes a small everyday moment strange and new.

## The sentence

> My shadow gets home five minutes before I do and waits by the front door, pretending it lives here.

## How it works

`main.py` writes the sentence (one line, 99 characters) to `/output/entry.txt`. The program uses only the Python standard library, validates the line against the competition gate (1–200 characters, a single line, not only whitespace), and produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
